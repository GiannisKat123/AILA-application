backend.database.entities.conversations

The Conversation ORM model represents a user-owned conversation record stored in the conversation PostgreSQL table. It is implemented with SQLAlchemy 2.0-style typing and PostgreSQL UUID columns.

Key features

  • PostgreSQL-native UUID primary key (id)

  • Human-readable name (conversation_name)

  • Foreign key to the owning user (user_id → app_user.id)

  • Timezone-aware last_updated timestamp (UTC)
